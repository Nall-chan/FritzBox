# Diese Library: FritzBox  

- Diese Library dient zur Anbindung von FritzBox Geräten, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um FritzBox-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der Fritz! API zu ergänzen.
- Der Entwicklersupport von Fritz! ist hier verfügbar: `https://fritz.com/pages/schnittstellen`
